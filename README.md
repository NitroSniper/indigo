## What is Indigo
`indigo` is a CLI tool that serves rendered markdown with styling via http leveraging web sockets to provide live updates to file changes.

## Features
- Live Preview: Updates preview on save. can specify how frequently it updates
- Flavoured: Currently comes with both `GitHub` and `Pico` Style
- Standalone
